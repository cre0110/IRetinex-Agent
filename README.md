# IRetinex-Agent

消化内镜AI辅助诊断平台，聚焦国内消化道早癌筛查刚需，针对内镜检查中图像雾化模糊、微小病灶易漏诊的临床难题开展技术攻关。

项目创新采用 DCP+IRetinex 融合图像增强算法，有效消除内镜雾化干扰；结合 YOLOv8I+MedSAM 模型实现息肉、巴雷特食管病灶的检测与像素级分割。依托 LangGraph 构建医疗智能体，打通图像质控、病灶识别、结果复核、辅助报告生成全流程。

模型经过多阶段训练与临床盲评验证，病灶检测、分割效果显著提升。产品支持云端SaaS、本地私有化部署以及SDK接口输出，面向基层医院、内镜中心、设备厂商提供服务，依靠临床数据飞轮持续迭代，助力提升消化道早筛水平，充当内镜医生的“第二双眼睛”。
